One word — the word an agent says when it has no idea what to do — written deterministically to `/output/entry.txt` for make.fun's "The Agent's Uh-Oh" bounty.

## Run it

```sh
python3 main.py
```

Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
